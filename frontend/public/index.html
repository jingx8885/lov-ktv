02 · Ritual

三步，房间就亮了

  1. 01
    电视开房

    盒子或浏览器打开电视页，墙上出现房间码和二维码。

  2. 02
    手机搜歌

    扫码进同一间房。先试听确认，再丢进曲库排队。

  3. 03
    扫色开唱

    伴奏、人声、MTV 就位。原唱伴唱随时切，下一句已经等在灯里。

Lookbook

舞台上真正用得到的东西

Search

搜歌名，不是传文件

大部分人手机里没有母带。所以主路是搜歌下载：歌名进曲库，处理自动跑完。

  • 歌名 / 歌手直接搜
  • 先试听，再入库
  • 队列、顶歌、切歌
  • 原唱 / 伴唱不中断

Split

伴奏是拆出来的，不是将就的

UVR ONNX 做人声分离。卡拉 OK 轨留给你，导唱轨在需要时再叠回去。

  • onnxruntime，不背 Torch
  • 伴奏 + 人声双轨
  • 处理完缓存在盒子上
  • 可挂 MTV 当背景

Color

中日英，三种扫色语法

官方时间轴优先。中日走到字，英文走到词，日语注音贴在字头上。

  • 当前句 + 下一句
  • 十尺电视也能看清
  • ASS / LRC / JSON 都留
  • 字幕外挂，不烧录

04 · Notes

上场前会问的

一定要 Android 电视吗？
不用。浏览器打开电视页就能唱。Android TV 是把宿主和缓存装进盒子里。
歌从哪来？
按歌名搜：网易外链，再到 SoundCloud、YouTube。只给自己的房间用，不二次分发。
没有官方歌词怎么办？
可以粘贴歌词。再没有就走转写。有官方 LRC 时，以官方轴为准。
要不要本机装 Torch？
不要。人声分离是 ONNX。镜像里已经烤好模型。
断网能唱吗？
已经处理好并缓存在盒子上的歌可以。新歌还是要处理端在线。
能当公开曲库网站吗？
不能。这是家庭 / 包厢自托管。不要公开发布媒体文件。
