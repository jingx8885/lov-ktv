# 学习模块题库升级需求

## 目标

把“歌词字段拼选择题”升级为“高质量知识点 + 多题型候选 + 自适应复习”的歌曲语言学习系统。歌曲是语料，题目负责记忆训练，听辨和跟唱负责输出验证。

## 当前问题

- 每句歌词最终随机抽一题，题量少、重复高、练习路线不稳定。
- 干扰项来自整首歌的粗粒度文本池，词性、长度和语义不匹配。
- 候选不足时用通用 fallback 凑题，容易产生明显坏题。
- 翻译、分词、假名/罗马音字段没有进入题目质量门槛。
- 只记录对错，不区分猜对、提示后答对、听辨答对和主动回忆。
- `word / sentence / listen / read / sing` 目前是入口分类，不是完整的记忆进阶链。

## 第一阶段（本次实现）

- 为题目生成增加质量元数据和审计统计。
- 选择题优先使用真实候选，降低 fallback 参与率。
- 按题目质量和稳定轮换选择题型，避免每次只随机抽到同一类题。
- 记录题目生成版本，支持后续重新生成而不破坏历史进度。
- 增加后端单元测试，覆盖坏候选、答案泄漏和题库审计。

## 第二阶段

- 把知识点抽象为 `word / phrase / sentence`，保存来源、音频区间、翻译置信度和难度。
- 增加词义、反向回忆、听辨、挖空、排序、句意理解和跟唱候选题。
- 干扰项按词性、长度、语义和发音相似度筛选；无法构造高质量干扰项时降级题型，不再硬凑四选一。
- 以知识点而不是题目为中心记录掌握度。

## 第三阶段

- 接入基于答题历史的间隔复习调度。
- 记录首次作答、提示、重试、响应时间和听后作答等信号。
- 将一关控制在 3–5 分钟：热身、主练、主动回忆、听唱挑战、结算。
- 增加 combo、挑战模式、薄弱点回练和歌曲掌握度分层。

## 验收标准

- 题库审计可以指出无效翻译、答案泄漏、重复题和 fallback 题。
- 正常题目的真实干扰项比例达到 100%；候选不足时明确降级而不是伪造语义。
- 同一首歌连续两轮练习不会固定得到完全相同的题型顺序。
- 历史学习记录不因题目生成版本变化而丢失。
